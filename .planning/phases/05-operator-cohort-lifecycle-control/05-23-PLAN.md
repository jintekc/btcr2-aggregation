**Two deliberate departures from the audit's grouped fix plan, stated because the round brief asks
for grouping changes to be justified.**

1. The audit puts #30 and #31 together in `packages/web/tests/cohort-form.spec.ts` and #17 and #23
   with the #1 residual in `packages/web/tests/operator-rows.spec.ts`. That grouping is kept. What
   changes is the METHOD for #31.
2. The audit says #31 "requires a src refactor": extract the edit form's field seeding into
   `packages/web/src/lib/cohort-form.ts` as an exported `formFromDraft`, mirroring the
   `formFromSnapshot` precedent. That proposal existed only because no spec in this repo could
   render a component, and it is explicit about that ("Every fix above is deliberately written to
   avoid that"). 05-21 removed the constraint. Rendering `DraftEditForm` and reading its field
   values back from the markup pins the ACTUAL seeding expression, where an extracted helper would
   pin a copy of it and leave the component free to stop calling it, which is the shape of the
   defect this whole round exists to close. So the refactor is not done and the render is.
