Purpose: three decisions in this phase are the kind a later phase undoes by accident unless they are written down with their reasons: that a cohort's fate is declared out of band BEFORE the library call because the stop primitive is silent, that the transport's single advert slot must be repaired after every settle or canceling one cohort silently un-advertises its siblings, and that runtime settings deliberately do not persist.   <action>
Write `docs/adr/0017-runtime-lifecycle-control.md` following the repository's ADR format. Record five decisions with their reasons and their consequences, each citing the verified library behavior that forced it:
  1. Declare intent, then stop. The runner's stop primitive emits no event and rejects the cohort's completion through the same channel a whole-runner shutdown uses, so a cohort's fate is written into a per-service intent registry BEFORE the library call and read by both fate consumers. Classifying a terminal cause by matching on error message text is forbidden.
  2. Repair the advert slot after every settle. The HTTP transport holds exactly one advert slot, replays only that one to a new subscriber, and clears it when the owning cohort's advert loop stops, so any settle can silently make sibling cohorts unjoinable. The repair re-publishes the newest still-open cohort's advert and runs on cancel, on completion, and on failure.
  3. Env seeds, runtime overrides, no persistence. Environment variables seed the boot value, the console edits the in-memory value, and a restart returns everything to the environment. Persistence is deliberately absent because it would change the product's stated state model, which is durability requirement territory for a later milestone.
  4. The broadcast switch is one-way within a session. Runtime power points only toward disabling money movement; re-enabling is a boot-environment act, preserving the layered mainnet guard rails. In-flight cohorts finish under the mode they started with, decided by comparing each cohort's advertise time against the moment the switch engaged.
  5. A per-cohort discovery window can only shorten. No timing value in the pinned aggregation library is per-cohort, so the app enforces the window itself with an intent-tagged stop, and a requested window above the runner-level cohort lifetime is refused at save with the real ceiling named.
State clearly that this ADR AMENDS rather than supersedes the polled monitoring read model ADR: the operator actions log rides the existing polled read, and no new event-stream channel is introduced.

Extend `docs/DEPLOY.md` with the Phase 5 operator controls: canceling and finalizing a cohort, pausing and resuming advertising and what pause does and does not do, the settings surface and the restart-returns-to-environment model, the one-way broadcast switch and how to turn broadcast back on, ended-record dismissal, test peers as a solo rehearsal tool, the participant chain-endpoint override and its browser-request constraint, the wallet PSBT registration path, and participation terms including the honest statement that they are enforced in the web app and that a client speaking the protocol directly joins without the step. Add every new environment variable to the variable table with its default and effect, and add the same variables with the same defaults to `docker-compose.yml`. Do NOT name any specific external wallet as compatible: the exported PSBT is standards-correct but wallet interoperability was not verified in this environment.

Create `docs/UPSTREAM-LIMITS.md` consolidating the known upstream library limits into one referenceable document: the single advert slot, the absence of a per-seat release API (added by this phase), no seat release on abandonment, the silent duplicate and surplus opt-in drop, the ignored advert repeat interval, the envelope-skew replay rejection window, and the deepest-first coin selection with only a dust floor. For each, state the observed behavior, the pinned version it was observed against, and the app-side workaround this repository uses. Note at the top that filing these upstream is still queued and is not done by this phase.
