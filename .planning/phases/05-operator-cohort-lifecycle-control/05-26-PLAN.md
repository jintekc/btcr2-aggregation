<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored acceptance to a third-party verifier | The terms-hash format is frozen and is meant to be checkable by someone outside this app, so its digest must be the standard one. |
| operator action to the audit trail | The operator-actions log is the record of who stood broadcasting down and when, so bogus duplicates degrade it. |
| service boot config to enforced ceiling | An unenforced ceiling means the console promises a window the runner will overrule. |

| T-05-26-03 | Spoofing | the live-mode test-peer disclosure | medium | mitigate | Drive the shipped spawn path in both modes, so neither a false live caveat nor a silent omission ships. |
