<objective>
Drive three server-side transitions that no test has ever completed: a successful window edit, the
unknown-draft refusal's body, and the dismissal of a record that expired rather than one that was
canceled.

Purpose: an operator who clears a timing window and saves is told "empty means use the service
default", and the code that makes that true has never run under test, because every existing edit
row throws in validation first. Separately, dismissing an expired row currently risks telling every
anonymous participant that the cohort was deliberately canceled, turning a lapse into an accusation;
05-19 built the carry that avoids it and added rows for the canceled leg only.

Output: two round trips, one asserted refusal body, one anonymous fate read after an expiry
dismissal, and a corrected `05-19-SUMMARY.md`.
</objective>
