## Trust Boundaries

Consolidated from the 44 per-plan boundary tables (recurring boundaries named once).

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| anonymous client -> gated operator surface | Every mutating operator verb sits behind `requireSameOrigin()` + `requireOperator()` prefix guards on `/v1/operator/*`; anonymous callers get 401 before any handler runs, and unknown/settled/never-existed ids share one 404 body. | operator credentials, cohort lifecycle commands |
| operator session -> runner protocol state | Gated verbs drop or mutate real protocol state for seated participants; blast radius is bounded to one cohort per verb. | cohort configs, member rosters, protocol phase state |
| service -> public directory / status / config | Canceled and paused state reaches anonymous readers as absence or a single deliberate bit; no reason strings, member lists, counts, or holder fields leak to anonymous surfaces. | directory listings, paused bit, network config, terms text |
| participant -> join / terms surface | Join-gate acceptance records are hash-addressed public statements; refusal sentences name the field class, never the refused value. | signed updates, acceptance records, terms hashes |
| boot env -> runtime settings holder | Env seeds are bounds-checked at boot; malformed seeds warn and fall back (service still boots); the settings surface mounts ONLY when `OPERATOR_PASSWORD` is set, read fail-closed (`=== true`). | env var seeds, operator password, terms/name seeds |
| browser console -> service session | The Zustand operator store scopes every gated answer to the session round that asked (16 enumerated capture sites); session-boundary crossings wipe the gated slice via `gatedSliceReset()`. | session cookie, gated telemetry slice, operator action log |
| npm/pnpm supply chain | Phase 5 installed zero packages; every `T-05-NN-SC` row asserts an empty `pnpm-lock.yaml` diff. Any future dependency must run the package-legitimacy gate first. | build-time dependency graph |
