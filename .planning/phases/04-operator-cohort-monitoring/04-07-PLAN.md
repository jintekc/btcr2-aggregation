## Phase Goal

See ROADMAP.md Phase 4 + the live-path core. This plan closes the participant-side honesty gaps the live UAT surfaced: awaiting-funding waiting copy + a live join-time notice (D-44), the stall-copy misattribution fix keyed on the `validation-requested` fact (D-45), and the unconfirmed-signal resolve guard that returns a retryable outcome instead of a 500 (D-46).

<objective>
Ship the three participant-surface fixes that make the live path honest end to end: (1) a join-time live notice + awaiting-funding waiting copy driven by a NEW additive public funding-signal read (never the frozen anchor read, D-44/D-26); (2) the stall-copy fix that records the `validation-requested` event as a store fact and rekeys the stall predicate so a genuine collecting-updates stall is distinguished from an unexplained co-signing death (D-45); (3) a service-side guard in the resolve path that detects the mempool-resident-signal condition and returns an honest retryable outcome (D-46).

Purpose: a participant on a live cohort gets honest copy while waiting for funding, the stall copy stops misfiring, and resolving against an unconfirmed signal returns a clear "try again after it confirms" instead of a 500.
Output: public funding-signal read + participant awaiting-funding/join-notice copy + rekeyed stall predicate + resolve guard.
</objective>
