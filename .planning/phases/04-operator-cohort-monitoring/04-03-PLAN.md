<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SERVICE_NAME env -> public header | An operator-supplied SERVICE_NAME is rendered as text on an anonymous surface; it must be treated as display text, never as markup/URL. |
| poll status -> render decision | A 401 must route to re-login and a network/5xx must freeze; conflating them would either strand a session or leak liveness. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-03-01 | Cross-site scripting | SERVICE_NAME render | medium | mitigate | Rendered as React text content (auto-escaped), never dangerouslySetInnerHTML; it is an operator boot constant, not participant input. |
| T-04-03-02 | Information Disclosure | mode/esplora chips | low | accept | Mode/network/esplora reachability are public operational facts already implied by /v1/config + /v1/status; the health strip is operator-gated regardless. |
| T-04-03-03 | Spoofing | freshness indicator | low | mitigate | Freshness derives from the store's own `lastUpdated`, updated only on an `ok` read; a stale/unreachable read freezes the label honestly rather than showing a fresh time (D-25). |
</threat_model>
