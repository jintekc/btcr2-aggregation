## Phase Goal

See ROADMAP.md Phase 4 + the live-path core (D-55). This plan is the honesty-critical funding stage: a watch-only, auto-detecting funding surface (D-36) with a consistent suggested minimum (D-37), the clamped funding wait that throws its specific reason before either library timer (D-38), blind-lapse honesty (D-39), recovery-key + mainnet disclosure (D-40/D-42), and the hermetic mocked-chain e2e proving awaiting-funding -> funded auto-advance (D-47).

<objective>
Build the cohort-beacon funding stage end to end, watch-only (the app never holds or spends funding keys): a single `classifyFunding` predicate reused by both the operator display watch and the authoritative onProvideTxData wait so watch and builder can never disagree (D-36); one consistent suggested-minimum number (D-37); the per-cohort runtime clamp that throws `funding never arrived` from inside onProvideTxData before phaseTimeoutMs/cohortTtlMs fire (D-38); blind-lapse honesty gated on the last observation being a successful empty read (D-39); always-shown recovery-key state and mainnet real-money + change-routing lines (D-40/D-42); esplora-outage stale-honesty (D-43); and the hermetic stateful-mock e2e that actually exercises the awaiting-funding -> funded transition (D-47).

Purpose: an operator can fund a real cohort beacon from their own wallet and watch it advance honestly; the wait fails with the right reason, never a generic timeout.
Output: funding-watch.ts + tx.ts clamp + funding DTO in monitor + FundingStage.tsx + stateful mock e2e.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator wallet -> beacon address | The operator funds from their own external wallet; the app is watch-only and never holds or spends funding keys. |
| watch predicate vs builder | The watch and the tx builder must agree on spendability, or the operator funds against a wrong threshold. |
| chain observation -> terminal claim | A terminal "funding never arrived" must rest on an observed empty read, never on a blind wall-clock lapse. |
